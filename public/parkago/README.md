# ParkaGo PWA (GitHub Pages)

GitHub Pages üzerinde açılan, telefona ana ekrandan kurulabilen ParkaGo arayüzü. Uygulama adresi: https://erasyl2004a-del.github.io/parkgo/parkago/

## Telefona kurulum
- iPhone: Adresi Safari’de açın, Paylaş > Ana Ekrana Ekle.
- Android: Adresi Chrome’da açın, menüden Uygulamayı yükle seçeneğini seçin.

## Demo sınırları
Bu yayın mevcut HTML prototipidir. Kayıt ve e-posta doğrulaması, tarayıcı içinde çalışan demodur; gerçek Gmail gönderimi, cihazlar arası hesap senkronizasyonu, gerçek ödeme ve bariyer/QR doğrulama sunucusu bağlı değildir. Otopark verileri örnektir. Gerçek kullanıcı verisi veya ödeme kabul etmeyin.

Bu klasör, var olan `parkgo` sitesinin `public/parkago/` alanında sunulur; ana ParkGo sayfasının yerini almaz. GitHub Actions derlemesi tamamlandığında otomatik yayımlanır.
